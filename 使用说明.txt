雅思学习APP 本地版 使用说明
================================

一、首次安装与日常使用
  首次请安装 Node.js 22.13 或更高版本，再联网运行「安装依赖.bat」。
  依赖安装完成后，双击「启动雅思学习APP.vbs」→ 稍等片刻（首次约 10~30 秒），
  浏览器会自动打开应用，即可开始学习。
  不需要联网，也不需要登录 ChatGPT。

二、文件说明
  启动雅思学习APP.vbs    日常使用入口（无黑窗，推荐）
  启动雅思学习APP.bat    调试版：显示服务日志窗口，出问题时用它排查
  停止雅思学习APP.bat    一键停止本地服务
  安装依赖.bat           首次下载后必须运行，也可用于修复依赖
  dev.log                服务运行日志（启动失败时查看）

三、常见问题
  Q: 双击 vbs 后提示"缺少运行依赖"？
     A: 先双击「安装依赖.bat」完成安装，再重新启动。

  Q: 提示"端口 3000 已被其他程序占用"？
     A: 关闭占用 3000 端口的程序，或先运行「停止雅思学习APP.bat」，
        再重新启动。

  Q: 浏览器打开后是空白页 / 加载失败？
     A: 打开「启动雅思学习APP.bat」查看日志窗口中的报错信息；
        也可把 dev.log 内容发给维护者排查。

  Q: 想换浏览器打开？
     A: 服务启动后，在任意浏览器地址栏输入 http://localhost:3000/ 即可。

四、离线使用说明
  依赖安装完成后，以下本地资源可以离线使用：
  - 全部 990 句、题库、听力材料、音频（MP3 均在本地）
  - 单词查询：内置 5 万词离线词典（ECDICT 开源词典库，
    词典式人工释义 + 音标 + 词性，含牛津3000核心词与
    ielts 考试标签，断网也可查词）
  - 跟读发音（浏览器内置语音，使用 Windows 自带语音包）
  - 学习记录（保存在浏览器本地存储）
  联网时，离线词典未收录的生僻词会回退到在线翻译；
  断网时仅生僻词查询无结果，其余功能不受影响。
  注意事项：
  - 请勿删除 public/fonts 文件夹（内含本地字体）。
  - 请勿删除 public/dict/ecdict.json（内置离线词典数据）。

五、技术信息（给维护者）
  基于 Next.js 16 / Vinext / Vite 构建，运行 npm run dev（开发模式）。
  依赖 Node.js 22.13+，请勿删除本目录中的 node_modules（占磁盘约 800MB）。
  本目录为独立副本，与原项目文件互不影响；如需更新程序内容，
  请重新生成副本或将新版本复制进来。
